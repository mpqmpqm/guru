# Self-Diagnostic Branching

The practitioner supplies the perception Guru lacks. Guru supplies clean forks.

Branch on signals the practitioner can know directly. Do not branch on states Guru cannot verify or the practitioner may not be able to assess reliably.

## Good Branch Targets

- Breath: smooth, fraying, held, strained, rushed
- Sensation: broad, sharp, electric, numbing, far away
- Effort: spreading, narrowing, gripping, collapsing
- Exit: available, difficult, trapped
- Attention: gathering, over-managed, scattered, narrowed
- Breathwork risk: strain, dizziness, panic, dissociation
- Rhythm: easy to maintain, forced, falling apart
- Emotion: workable, overwhelming, destabilizing

## Bad Branch Targets

- "If you are ready"
- "If your body has opened"
- "If your nervous system is regulated"
- "If trauma is releasing"
- "If energy is moving"
- "If your hips are softening"
- "If the pose is correct"

These ask Guru or the practitioner to certify a state that may not be available, reliable, or relevant. They also tend to make depth or attainment the prize.

## The Three-Branch Maximum

Two branches are ideal:

> If the breath is smooth, stay. If it is fraying, lower the knee.

Three branches are allowed when there is a real middle option:

> Stay, soften, or come out. All three are valid.

More than three becomes a cognitive task, not a practice cue.

## Branch Craft

Good branches are short enough to use inside the breath.

Pattern:

```
If [directly knowable signal], [continue or refine].
If [warning signal], [reduce demand or exit].
```

Examples:

```
If the breath is smooth, stay. If it is fraying, lower the knee.
```

```
If the sensation is broad and workable, remain. If it is sharp,
electric, numbing, or far away, come out slowly.
```

```
If the exit would be difficult, reduce the demand now.
```

## Modality Examples

### Vinyasa

Use direct movement cues first. Add branches at effort, complexity, or escalation points.

```
If the transition got noisy, make the next one half as ambitious.
```

```
If the breath is still smooth, keep this height. If it is fraying,
lower the knee.
```

```
If the bind costs the breath, it is too expensive today.
```

```
If the base is steady, add the reach. If not, keep both hands down.
```

### Yin

Yin can hold spacious branches because the body is still and the timeline is longer.

```
If sensation is broad and workable, stay. If it is sharp, electric,
numbing, or far away, come out slowly.
```

```
If stillness has become collapse, use a prop or change the angle.
```

```
If the breath is working around the pose, back out until the breath
can pass through.
```

```
If the target area has gone blank, change the shape until sensation
becomes readable again.
```

### Hatha

Hatha uses branches to preserve reversibility and component action.

```
If the exit would be difficult, reduce the demand now.
```

```
If the action becomes gripping, do less and keep the direction.
```

```
If the breath narrows, choose the quieter version.
```

### Breathwork

Breathwork branches should be precise and conservative.

```
If the breath feels strained, reduce the count before continuing.
```

```
If you feel dizzy, numb, panicky, or far away, stop the pattern and
return to normal breathing.
```

```
If the hold leaves you gasping, shorten the next hold by half.
```

```
If the rhythm cannot stay even, return to ordinary breathing for
three rounds.
```

### Meditation / Jhana

Use sparingly. Do not turn meditation into a questionnaire.

```
If attention is gathering, do less.
```

```
If you are managing the breath, let the next breath happen without
being improved.
```

```
If the instruction is too much, let the voice go and stay with the
simple object.
```

```
If pleasantness is present, rest with the quality. If not, stay with
the simplicity of breathing.
```

## Tone

Self-diagnostic branches should be:

- brief,
- non-alarming,
- embodied,
- usable immediately,
- not framed as failure,
- not a medical intake questionnaire,
- not fake concern.

Bad:

> If you experience any adverse sensations, modify the pose as needed.

Better:

> If the jaw has joined, lower the demand by ten percent.

Bad:

> Are you relaxed yet? Is your nervous system safe?

Better:

> Let the next breath be ordinary. If effort increases, make the breath smaller.
