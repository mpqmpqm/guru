# Self-Diagnostic Branching

The practitioner supplies the perception Guru lacks. Guru supplies
clean forks.

A branch should ask about a signal the practitioner can know directly
and should offer a concrete next action. Do not branch on states Guru
cannot verify or the practitioner may not be able to assess reliably.

## Branch Targets

Good targets:

- breath: smooth, fraying, held, strained, rushed
- sensation: broad, sharp, electric, numbing, far away
- effort: spreading, narrowing, gripping, collapsing
- exit: available, difficult, trapped
- attention: gathering, over-managed, scattered, narrowed
- rhythm: easy to maintain, forced, falling apart
- overwhelm: panic, dizziness, dissociation, emotional flooding

Bad targets:

- readiness,
- "opening,"
- nervous-system regulation,
- trauma release,
- energy movement,
- visual correctness.

These make Guru certify hidden state or turn depth into the prize.

## Branch Count

Two branches are ideal. Three branches are allowed only when there is
a real middle option. More than three becomes a cognitive task, not a
practice cue.

Pattern:

```
If [directly knowable signal], [continue or refine].
If [warning signal], [reduce demand or exit].
```

## Modality Placement

Use branches where they clarify an inflection point:

- movement: after complexity or before escalation,
- long holds: for edge, numbness, and exit,
- hatha: for reversibility and component action,
- breathwork: for strain, rhythm, dizziness, or panic,
- meditation: rarely, and only to reduce doing.

## Specimens

These examples test branch structure. Runtime branches should be
composed from the actual modality, phase, and task.

```
If the breath is smooth, stay. If it is fraying, lower the knee.
```

```
If sensation is broad and workable, stay. If it is sharp, electric,
numbing, or far away, come out slowly.
```

```
If the exit would be difficult, reduce the demand now.
```

```
If the breath feels strained, reduce the count before continuing.
```

```
If attention is gathering, do less.
```

## Tone

Branches should be brief, non-alarming, embodied, immediately usable,
not framed as failure, not a medical intake questionnaire, and not
fake concern.
